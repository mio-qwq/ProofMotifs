# SC-011: a polynomial-only cyclic incidence certificate

Date: 18 October 2026. Task: PM-CYCLE8-B.

This is **Level 0 classical cyclic-code infrastructure** and a shorter
finite certificate for the already established F_243 incidence rank. It
does not assert a historically new coding theorem or replace the uniform
completion and Fourier proofs. Its practical value is a standalone F_3
polynomial verifier: one cyclic orbit of 121 actual edges already forces
the same affine kernel as the full 1,210-edge hypergraph.

**PM-THEOREM-0015** records the cyclic gcd rank criterion and its finite
certificate. **PM-COUNTEREXAMPLE-0006** below records a limitation of
reconstructing hypergraph automorphisms from the incidence kernel: these
two hypergraphs have the same row code but different automorphism groups.
This refutes a project proposal, not an identified published conjecture.

The code imports no other project module, constructs no character table,
enumerates no field characters, and performs no matrix-rank computation.
No Lean or human verification is claimed.

## 1. Classical cyclic-code description

Let H be a finite cyclic multiplicative subgroup of a characteristic-three
field, let `H=<gamma>` have order N, and label vertices by exponents
modulo N. Consider distinct zero-sum triples in H. Multiplication by
gamma translates their exponent sets.

Choose normalized representatives `{0,i,j}` for all edge orbits and put

`h(Z)=Z^N-1`, `p_e(Z)=1+Z^i+Z^j`.

Identify row vectors with polynomials in `R=F_3[Z]/(h)`. All translates
of an edge row are the cyclic shifts `Z^t*p_e`. Their row span is
therefore the ideal generated by the p_e in R. If

`d=gcd(h,p_e for all e)` is monic,

then this ideal is exactly `(d)` in R. Indeed every generator is divisible
by d, and the polynomial Bezout identity expresses d as a combination of
h and the p_e. The vectors represented by

`d,Z*d,...,Z^(N-deg(d)-1)*d`

form a basis of this ideal: they are independent by their distinct leading
degrees and span by reduction modulo h. Consequently

`incidence row rank = N-deg(d)`,

`incidence kernel dimension = deg(d)`.

The same statements hold for any selected collection of edge orbits.
They describe a standard cyclic row code. The kernel here is the
orthogonal space of that row code; it should not be identified with the
row ideal itself. No reciprocal-polynomial convention is needed for the
rank certificate.

No squarefree or character decomposition is required for this ideal
argument. In the present multiplicative-subgroup setting, 3 cannot divide
N anyway. Every nonempty edge orbit has size N: a nonidentity multiplier
has no fixed vertex, and a permutation of a three-element set without a
fixed point has order three, impossible in a group of order coprime to
three.

## 2. An explicit seed in F_243

Put

`M(Z)=Z^5+2Z+2`,

`D(Z)=1+2Z^2+2Z^5+Z^6=(Z-1)*M(Z)`,

`h(Z)=Z^121-1`, `p(Z)=1+Z^4+Z^68`.

The certificate proves by exact polynomial identities over F_3 that

`h=D*Q_h`, `p=D*Q_p`,

`A*h+B*p=D`.

Thus D is exactly the monic gcd of h and p. The supplied A and B have
degrees 61 and 114; their complete coefficient arrays and the two
divisibility quotients are in the deterministic certificate. The verifier
multiplies and adds these polynomials to check the identities; it does
not trust a reported gcd degree or rerun the extended gcd for this step.

### Field and subgroup identification

The polynomial M is irreducible. The verifier checks

`Z^243=Z mod M`

and a supplied Bezout identity proving

`gcd(M,Z^3-Z)=1`.

Since degree five is prime, the first identity forces every irreducible
factor to have degree dividing five, and the second excludes degree-one
factors. The first identity also excludes repeated factors because
`Z^243-Z` has derivative -1. Thus M itself is irreducible.

Let `gamma=Z mod M` in the field `K=F_3[Z]/(M)`. The verifier checks

`gamma^121=1`, `gamma^11 != 1`.

Because `121=11^2`, gamma has order exactly 121. Its subgroup H is exactly
the nonzero squares: every element of the odd-order group H is a square
within H, and the squaring map on K* has a two-element kernel, so the full
square set also has 121 elements.

Divisibility `M|p` proves

`1+gamma^4+gamma^68=0`.

These vertices are distinct because gamma has order 121. In gamma power
coordinates they are

`1`, `gamma^4`, `2+2gamma^4`.

Their base-three encodings are 1, 81 and 164. Relative to the earlier
presentation `alpha^5+2alpha+1=0`, one may take `gamma=-alpha`, which is
the element encoded as 6 there. The graph is therefore the same F_243
square hypergraph up to the stated field-coordinate change.

The seed orbit consists of 121 distinct true hyperedges. Its row code has
rank `121-deg(D)=115`, so its kernel has dimension six.

## 3. Why the single orbit already forces every edge equation

Restrictions to H of functions

`x -> c+ell(x)`, where `c in F_3` and ell is F_3-linear on K,

form a six-dimensional space. Independence follows because a nonzero
affine function has at most 81 zeros in K, whereas H has 121 points.
Every such function vanishes on every edge sum: the constant contributes
`3c=0` and the linear part contributes `ell(u+v+w)=0`.

Thus the full hypergraph kernel contains these six independent affine
restrictions. It is contained in the seed-orbit kernel, which already
has dimension six by the polynomial certificate. The two kernels and
the affine space are therefore equal. Equivalently, the 121 cyclic seed
rows span the complete row code of all 1,210 edges.

This finite conclusion uses the seed certificate and the elementary
affine inclusion, not the uniform Fourier spectrum theorem. It does not
claim that the 121 seed equations are linearly independent, minimal,
or uniquely suited to this field; their rank is 115.

## 4. PM-COUNTEREXAMPLE-0006: the row code does not determine the edge set

Let J be the 121-edge cyclic seed hypergraph and H the full 1,210-edge
square zero-sum hypergraph on the same 121 vertices. Section 3 proves

`ker(M_J)=ker(M_H)=the affine restriction space`,

and hence equality of their incidence row codes. Nevertheless

`Aut(J)=C_121`, whereas `|Aut(H)|=605`.

Here is the exact reason for the different groups. Any automorphism of J
preserves its incidence kernel. Since that kernel is the complete affine
restriction space, the coordinate-function argument of
[SC-009, Section 2](../SC-009/RESULTS.md) extends it uniquely to an affine
map `L(x)+b` of K. Its linear part is invertible because the square set
affinely spans K. The square set sums to zero and has size 121, which is
1 modulo three. Summing the extension on that set forces b=0.

Thus L is an additive bijection preserving the square set and its
complement. Every nonzero difference quotient `L(x-y)/(x-y)` is a
square. The classical Carlitz theorem, in exactly the form and with the
source specified in SC-009, forces `L(x)=s*x^(3^j)` with s a square and
`0<=j<5`. This is a mathematical dependency on that prior theorem; the
polynomial checker does not prove Carlitz or enumerate arbitrary
hypergraph permutations.

Square multiplication always preserves a cyclic edge orbit. Frobenius
multiplies the exponent set by three. Normalize translation orbits by
taking the lexicographically least sorted set after subtracting each of
its three elements modulo 121. Applying the five Frobenius powers gives:

| j | Canonical orbit pattern of `3^j*{0,4,68}` |
| --- | --- |
| 0 | `{0,4,68}` |
| 1 | `{0,12,83}` |
| 2 | `{0,7,36}` |
| 3 | `{0,13,34}` |
| 4 | `{0,19,58}` |

These distinct patterns are recomputed by the standalone checker. Thus
only j=0 preserves the seed orbit, and Aut(J) consists of its 121 square
scalings. In particular the selected edge orbit is **not** Frobenius
invariant. The full H, by contrast, contains all zero-sum triples and is
preserved by all 605 square-scaling/Frobenius actions, with the matching
upper bound already established in SC-009.

The result demonstrates a precise limitation: an incidence kernel can
recover the ambient affine space and constrain automorphisms without
recovering the particular hyperedge collection or its automorphism group.
The code automorphism group of their common row code must not be silently
identified with the hypergraph automorphism group of J.

## 5. Negative control: an arbitrary single edge orbit can be too weak

In F_81 use the field polynomial

`L(Z)=Z^4+2Z^3+Z^2+1`.

Its root gamma has order 40 and generates the square subgroup. The control
checks `Z^81=Z mod L`, `gcd(L,Z^9-Z)=1`, and the order tests
`gamma^40=1`, `gamma^20 != 1`, `gamma^8 != 1`. These give irreducibility
and exact order 40. Both following sparse polynomials vanish at gamma,
so they represent actual distinct zero-sum seed triples:

| Seed exponents | Degree of gcd with `Z^40-1` | Cyclic row rank |
| --- | ---: | ---: |
| `{0,5,30}` | 15 | 25 |
| `{0,1,9}` | 5 | 35 |

The full affine kernel in this field has dimension five, and the second
row orbit already forces it by the same dimension argument. The first
orbit has a 15-dimensional kernel and does not suffice. This is a concrete
negative control against assuming that any one normalized edge can replace
all incidence equations. Choosing a valid seed and proving its gcd are
both necessary parts of the finite certificate.

## 6. Reproduction and trust boundary

```bash
python tools/cyclic_incidence_certificate.py > /tmp/cyclic-certificate.json
python tools/cyclic_incidence_certificate.py --check /tmp/cyclic-certificate.json
python -m unittest discover -s tests -p test_cyclic_incidence_certificate.py -v
```

The report stores the full Bezout and divisibility witnesses, exact field
identification, the rank receipt, a canonical JSON SHA-256 and the F_81
proper-orbit control. The digest supports integrity; acceptance comes from
the algebraic identities and the proof above. Tests corrupt the incidence
Bezout identity, a divisibility quotient, the proposed gcd and the field
irreducibility witness; each false certificate is rejected. Another test
forges Frobenius invariance of the seed orbit and is rejected. The
verified orbit patterns support the written group comparison, whose
affine-extension/Carlitz dependency is explicit in Section 4.

This supplies reusable exact cyclic-code infrastructure and a smaller
independent certificate for an existing finite result. It does not by
itself prove the uniform theorem for arbitrary subgroups, select a
sufficient orbit in every field, establish an optimal test count, or
demonstrate historical originality. Standard cyclic coding is the closest
prior theory, and is the appropriate conservative classification.

## 7. Exact next question

**PM-QUESTION-0001.** For every m>=3, is there at least one square-multiplication
orbit of distinct zero-sum triples whose row code equals the complete square
hypergraph row code? Equivalently, can a valid trinomial seed have gcd degree
m+1 in every degree? Positive instances in m=3,4,5 are known here; the F_81
bad orbit disproves the stronger assertion that an arbitrary seed suffices.
This is an open project question, not a historical novelty claim. Compare
cyclic-code precedents before attempting a general proof or new enumeration.
