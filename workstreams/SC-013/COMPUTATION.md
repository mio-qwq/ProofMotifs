# SC-013 exact computation: single square-edge orbits

Date: 18 October 2026. Task ID: PM-CYCLE9-B.

Research question: can a single multiplication orbit of zero-sum square triples
force the complete affine incidence kernel? Can connectivity characterize a
sufficient orbit? The infinite existence question remains open here.

Known assumptions and evidence: the complete square zero-sum incidence kernel
is the affine restriction space for m >= 3 (SC-009); the classical cyclic
polynomial rank criterion is proved in SC-011. This work independently builds
finite field presentations and exact seed certificates. It does not assume
that every valid seed, or every connected seed, suffices.

Allowed scope: `tools/single_orbit_search.py`, its tests, and this computation
note. The coordinator owns theorem statements, shared state, frozen experiment
outputs, review, integration and publication. No push is performed by this task.

## Arithmetic and independent checks

For each degree m=3,...,8, use the displayed monic polynomial M to represent
K=F_3[X]/M. Let x be its residue class and gamma=x^2. Field elements are
base-three coordinate integers. Multiplication by x is the coordinate
recurrence obtained from M. The code enumerates exactly q-1 distinct nonzero
powers, then checks that the cycle returns to 1. This proves that every
nonzero quotient-ring element belongs to the unit group generated by x, hence
the quotient is a field and x is primitive. Storage uses O(q) power/log lists,
not O(q^2) field operation tables.

A separate list-polynomial implementation additionally checks Rabin
irreducibility (`X^q=X mod M` and proper prime-degree factor exclusions) and
primitive-order tests for every prime divisor of q-1. This checks the field
presentation independently of the coordinate recurrence.

A normalized seed is a canonical translation representative `{0,i,j}` with
`1+gamma^i+gamma^j=0`. Enumerating all squares a and testing whether -1-a
is a distinct nonzero square enumerates every normalized edge. Every orbit
contains such a normalization. Three-anchor canonicalization removes duplicate
representatives. There are no short edge orbits: multiplication acts freely
on individual vertices, and a nonidentity permutation of a three-point edge
without a fixed vertex would have order three, impossible since 3 does not
divide N=(q-1)/2.

A two-bitplane implementation computes gcd degrees over F_3; it does not
reinterpret this as binary polynomial arithmetic. Each reported degree is
independently verified by counting roots of the seed polynomial among all
powers gamma^k. Since Z^N-1 is squarefree and splits completely in K, that
root count is exactly its gcd degree. For each selected good seed and the
connected counterexample, full list-polynomial Bezout and divisibility
identities certify the gcd without trusting the search routine.

## Explicit connected but insufficient seed

In F_729 as above choose e={0,25,311}. It is a true edge seed, and
`gcd(25,311,364)=1`, so its multiplication-orbit hypergraph is connected.
Nevertheless, putting p=1+Z^25+Z^311 and h=Z^364-1 gives

```
gcd(h,p) = 2+2Z+Z^3+2Z^4+2Z^6+2Z^10+Z^13.
```

Its degree is 13, giving row rank 351, whereas the complete hypergraph has
rank 357. Full Bezout coefficients A,B and quotients appear in the report;
the verifier checks `A*h+B*p=D`, `D*Q_h=h`, and `D*Q_p=p`.

The good seed has gcd

```
D_aff = 2+2Z+2Z^2+2Z^3+Z^4+2Z^6+Z^7.
```

The extra factor is

```
D/D_aff = 1+2Z^2+2Z^3+Z^4+Z^5+Z^6.
```

The complete roots of D among powers gamma^k are the disjoint sets

```
{0}, {1,3,9,27,81,243}, {34,102,306,190,206,254}.
```

The last set is the extra Frobenius orbit of exponent 34. This gives an
explicit nonaffine sparse-kernel function

`f(u)=Tr_{F_729/F_3}(u^34)`.

For every t, the sum over the translated seed is

`Tr(gamma^(34t)*(1+gamma^(34*25)+gamma^(34*311)))=0`.

The code checks all 364 such sums. At the genuine full-hypergraph edge
`{1,gamma^5,gamma^255}`, its three values are respectively `0,0,1`, so the
sum is 1. Consequently f is not an affine restriction, since every affine
restriction sums to zero on every zero-sum triple. This certificate refutes
the proposed implication “connected seed implies sufficient row code,” not
the weaker existence question.

## Reproduction and controls

```bash
python tools/single_orbit_search.py > /tmp/pm_single_orbit_report.json
python tools/single_orbit_search.py --check /tmp/pm_single_orbit_report.json
python -m unittest discover -s tests -p test_single_orbit_search.py -v
```

The JSON is deterministic and includes the full selected polynomial
certificates, complete low-degree orbit lists, an independent root-count
receipt, and all values of the trace witness. No timing values enter its
canonical hash. Tests corrupt a Bezout polynomial, divisibility quotient,
claimed gcd degree, connectivity index and trace values, and remove an
orbit from a purported complete scan. Those false reports must be rejected.
A nonprimitive modulus control is also rejected.

before reading other current-cycle proposals. The coordinator subsequently

counterexample, extra root mode and trace separator were computed here.

Stop condition and handoff: the bounded certificate work is complete when

and determine whether their forbidden seed sets can cover all connected
