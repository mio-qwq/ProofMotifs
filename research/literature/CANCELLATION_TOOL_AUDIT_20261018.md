# PM-UNIFY-C: prior-art gap assessment

Independent review, 2026-10-18. Scope: read-only ProofMotifs; inspected INITIAL_REVIEW.md, mechanisms/COMPARISON.md, and original sources below. Ordinary web retrieval only; no ParallelSearch retry, expenses, Git operations, or external correspondence.

## Assessment

The current evidence supports a useful classification project and a plausible certificate-synthesis engineering question. It does **not** establish a new mathematical cancellation principle, a need for a new mathematical tool, or the claim that cancellation explains modern AI mathematical success. The three repository examples were deliberately selected calibration cases, not a neutral census. A mechanism present in both AI and human proofs does not by itself explain an AI advantage. Counting the word “cancellation” would also conflate weighted annihilation with unrelated uses such as small-cancellation group theory.

The strongest obstacle to an alleged universal theorem is explicit prior art: Waldron's Theorem 2.4 is the quotient/factorization theorem R|ker(U)=0 iff R=Q∘U for a surjective linear U. His Theorem 2.2 applies it to derivative operators and polynomial annihilation, with topology/open-map hypotheses for continuity and norm control. Describing the three calibration mechanisms as “kernel conditions” adds language but no theorem.

## First research falsification target

**F1: kill the vacuous unification before building a system.** State the proposed cancellation theorem with typed maps and all hypotheses. Freeze a computationally meaningful local operator U independently of the desired functional R. Try to derive the theorem using Waldron 2.4 / the first isomorphism theorem plus the source-specific lemma. If U is allowed to be R, or the quotient X→X/ker(R), the result is tautological. If every conclusion follows immediately from these existing results, retire the mathematical novelty claim and retain at most a language/algorithm project.

Require the proposed statement to survive three exact boundary tests already visible in the repository: (i) finite-field P=X^(q−1) has sum −1, and real-valued counting does not annihilate the constant term; (ii) a nonzero-mass density with F=1 defeats a zero-Lipschitz cancellation gain; (iii) deleting join stability or allowing only bottom leaves the signed empty-chain contribution 1. Characteristic must be explicit: in characteristic p, x^p has functional degree 1, while its ordinary degree is p. A representation that silently identifies these degrees fails before questions of usefulness arise.

If F1 passes with a genuinely residual obligation, the first engineering test should isolate **witness discovery**, not showcase checking. For the already-seen chain-toggle calibration, give only the parameterized join-semilattice statement, hide the proof, and require symbolic construction of the pivot and proof of all admissibility/involution facts; compare retrieval + existing tactics with any proposed shared layer under equal budgets. Label this calibration, not held-out discovery. Then repeat on genuinely unseen families with damaged-hypothesis controls. If the ordinary baseline solves the same targets with comparable cost, that falsifies the claimed need for the extra layer on those targets. Finite matching enumeration and a restatement of the desired zero sum are not acceptable symbolic certificates.

No unsuccessful search is used as evidence that a tool or theorem is new. This is a focused gap screen, not exhaustive historical priority certification.
