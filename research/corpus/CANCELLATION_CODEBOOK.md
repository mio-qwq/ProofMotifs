# Semantic cancellation codebook: development version 1

Date: 18 October 2026. This is a calibration instrument, not a completed
preregistration or an already performed corpus experiment. Controlling questions:
PM-H1–PM-H5 in `research/RESEARCH_PROGRAM.md`.

## Unit and inclusion rule

Use a semantic lemma application as the mechanism unit and a problem family
as the prevalence unit. A positive code requires all four:

1. a specified aggregate/operator and scalar domain, including convergence;
2. an independently checkable structural certificate, rather than the target
   equality restated as a premise;
3. a definite vanishing, first-surviving-term prediction, selection rule or
   quantitative improvement relative to a specified uncancelled estimate;
4. an inspected dependency path from that consequence to the submitted claim.

Code `uncertain` if the relevant body/dependencies have not been inspected.
Code `no` for routine rearrangement, an arbitrary A-B=0 rewrite, padding by
g-g, or a triangle-inequality estimate with no cancellation gain. A family-level
negative requires a sufficiently complete proof audit; absence in a local
passage does not establish it. Several mechanisms can be central in one proof.

## Independent annotation fields

Record: family/source/revision and exact evidence span; certificate type;
characteristic and coefficients; domain/action; observable/function class;
vanishing order and its definition; surviving term/gain; construction versus
verification burden; role and downstream dependencies; other bottlenecks;
local/full/claimed/formal/withdrawn validity; provenance and exposure; prior art;
counterexample after weakening a hypothesis; and uncertainty.

In particular, zeroth-moment cancellation is not automatically higher-order.
A classical mechanism in a valid proof is not evidence of a new tool. A useful
mathematical step need not be the generating model's discovery bottleneck.

## Representation and reliability gate

An invertible coordinate change can turn evaluation of the first coordinate
of (0,1) into 1-1=0: use T=[[1,1],[0,1]] and transform the functional by T^-1.
Thus a term/minus-sign count is not an invariant mathematical mechanism count.
Test equivalent coordinate, expanded/factored, lemma-inlined and paired-orbit
presentations before prevalence coding. Semantic labels should agree unless
the actual certificate or consequence changed. Record provenance masking and
coders' guesses about it; perfect blinding is not assumed.

Use two independent contexts for the same passages, retain initial labels,
adjudication and disagreements, and report only the independence achieved.
AI-context independence is not human review. Freeze reliability criteria,
unknown/withdrawal handling, estimand and stopping rules before a confirmatory
study; the pilot does not yet supply them.

## First mathematical comparison, already exposed calibration

Reconstruct on the same template: family197's finite-field line-sum and regular
incidence compatibility; family107's primitive-root/no-wrap/degree filtering;
family157's bilinear triangle identity and separate matching/entropy burden.
Compare what existing tools prove and what representation or certificate still
had to be discovered. Keep family085's mean-zero estimate and chain involution
as different-order controls. All are exposed calibration, not unseen transfers.

Then seek one precise discovery/transport operation that survives the prior-art
gate. A new target must be selected and its solution withheld before attempting
the transfer; no such success has yet been claimed. Descriptive sampling and
fixed-resource interventions support this mathematical work and are not a
replacement for it.
